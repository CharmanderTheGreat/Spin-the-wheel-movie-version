# 🎬 Reel Roulette — Movie Picker

Can't decide what to watch? Add your movie options, spin the wheel, and let chance pick tonight's feature.

A single-page, no-backend movie picker with a spinning roulette wheel. Built with plain HTML, CSS, and JavaScript — no frameworks, no build step, no API keys required.

## Features

- Add movies by title, with an optional link to where you can watch it
- Spin a roulette-style wheel to randomly pick from your list
- Your list is saved in the browser (`localStorage`), so it's still there next time you open the page
- Remove movies from your list anytime
- Works fully offline after the page loads — no external services needed

## How to Use

1. Open the page.
2. Type a movie title into the **Movie title** field (and optionally paste a link to where you can watch it).
3. Click **Add**. Repeat for as many movies as you want.
4. Once you have at least 2 movies, click **Spin the Reel**.
5. The wheel spins and lands on your movie for the night.

## Running Locally

No installation needed — it's a single HTML file.

1. Download `index.html`.
2. Open it in any web browser.

## Deploying to GitHub Pages

1. Create a new GitHub repository (or use an existing one).
2. Upload `index.html` to the repository (must be in the root, or in a `/docs` folder if you configure it that way).
3. Go to **Settings → Pages**.
4. Under **Build and deployment → Source**, select **Deploy from a branch**.
5. Choose your `main` branch and the `/ (root)` folder, then click **Save**.
6. GitHub will give you a live URL (usually `https://<your-username>.github.io/<repo-name>/`) within a minute or two — this is your free, shareable live demo link.

## Notes

- All movie data is stored locally in your browser. Clearing your browser data/cache will clear your list.
- Since data is stored per-browser, your list won't sync across different devices or browsers.
- No account, API key, or internet connection is required to use the app (aside from loading the page itself).
